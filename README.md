# Бронирование столиков

Тестовое задание ОСЬ. API бронирования на FastAPI, SQLite и async SQLAlchemy 2.0.

## Быстрый старт

### Локально

Из корня проекта с Python 3.13 и `uv`.

```sh
uv sync --locked
uv run alembic upgrade head
uv run uvicorn app.main:app
```

### Docker

```sh
docker compose up --build
```

Docker применяет миграции при старте и хранит базу в волюме `bookings`.

Эндпоинты и примеры запросов в [Swagger UI](http://localhost:8000/docs).

## Настройки

Локальная база - `bookings.db`. Другой путь можно задать через `DATABASE_URL` в `.env` по шаблону `.env.template`.

## Проверки

Тестирую сервис напрямую, API - через `httpx.AsyncClient`.

```sh
uv run pytest
uv run ruff check
uv run mypy
```

Те же проверки запускаются в CI.

## Решения

Правила бронирования вынес в сервис, чтобы тестировать их отдельно от HTTP. 

Перед подсчётом занятых столов открывается `BEGIN IMMEDIATE` для избежания race condition. 

Для тестов поднимаю временную базу с теми же миграциями Alembic.

Добавил базовый CI.
